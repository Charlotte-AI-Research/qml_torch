# Fall 2026 roadmap

This is the CAIR QML team roadmap. It is a shared software and learning plan, separate from any lead or member's independent research.

## Before active work

- Attend the interest meeting and choose a role.
- Create a clean Python environment and run the smoke tests.
- Complete the two-qubit tutorial; no quantum background is required.

## Weeks 1–2: shared foundation

Everyone runs the same small dataset through a classical baseline and the starter quantum layer. We record setup issues, define the API we actually want, and close beginner-friendly documentation tasks.

## Weeks 3–6: core layer

The implementation team improves validation, batching, output shape handling, and tests. The examples team writes a short tutorial. The benchmark team defines one comparison protocol with fixed seeds, metrics, and a runtime budget.

## Weeks 7–10: one comparison

We run one laptop-sized experiment and report accuracy, variance across seeds, runtime, and failure modes. A classical model remains a required baseline.

## Weeks 11–14: release and handoff

We polish documentation, package the example, present the result at a CAIR event, and leave issues that the next cohort can pick up.

## Explicit boundaries

Paper replication, dequantization studies, new application domains, hardware access, and claims of quantum advantage require a separate team proposal. They are not assumed deliverables for this club cycle.
