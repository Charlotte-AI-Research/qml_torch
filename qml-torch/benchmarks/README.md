# Benchmarks

> **What:** This directory contains repeatable experiments that measure
> runtime and compare classical and hybrid results across several seeds.
>
> **Why:** Measured results help choose safe defaults and prevent one unusually
> good run from being presented as general evidence.

This folder is reserved for reproducible runtime and multi-seed comparison
protocols, not cherry-picked result artifacts. Benchmark outputs should record
environment, configuration, seed, runtime, accuracy distribution, and limitations.
