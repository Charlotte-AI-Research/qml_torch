# Reporting

> **What:** This directory will format circuit diagrams, metrics, runtimes,
> settings, warnings, and saved result files.
>
> **Why:** Users need to see both their choices and the library's hidden defaults
> to understand and reproduce an experiment.

Future home of circuit diagrams, terminal summaries, metrics, run manifests,
dependency provenance, warnings, and incomplete-run status. Reports make hidden
defaults visible without forcing beginners to configure them.
