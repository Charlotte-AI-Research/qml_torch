# Encodings

> **What:** This directory will contain ways to place classical feature values
> into a quantum circuit, beginning with angle encoding.
>
> **Why:** Encoding has its own rules and shape requirements, so it should be
> testable without mixing it into circuit presets or training code.

Future home of named feature-encoding strategies and their constraints. Each
encoding should provide validation metadata and help text as well as circuit
operations. The initial list is decided by QMLT-001.
