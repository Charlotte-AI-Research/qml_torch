# Training

> **What:** This directory will train the classical baseline and hybrid VQC model
> using the same small experiment setup.
>
> **Why:** Shared training rules make the comparison easier to run and reduce
> accidental differences in data, seeds, epochs, and metrics.

Future home of small reusable supervised training and classical-versus-hybrid
comparison loops. Both models should share data splits, seeds, metrics, and
budgets wherever possible.
