# Circuits

> **What:** This directory contains the library's ready-made quantum circuit
> and VQC layouts.
>
> **Why:** Beginners should receive a safe circuit automatically instead of
> needing to design an ansatz gate by gate.

The v0.1 implementation provides one versioned, library-owned circuit preset.
Beginner users do not choose a gate-level ansatz, while reports identify the
hidden preset through the rendered circuit. This area does not contain training
loops, data loading, or CLI prompting.
