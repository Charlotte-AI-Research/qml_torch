# Circuits

> **What:** This directory will contain the library's ready-made quantum circuit
> and VQC layouts.
>
> **Why:** Beginners should receive a safe circuit automatically instead of
> needing to design an ansatz gate by gate.

Future home of versioned, library-owned circuit presets. Beginner users will not
choose a gate-level ansatz, but reports must identify the exact hidden preset used.
This area should not contain training loops, data loading, or CLI prompting.
