# Validation and compilation

> **What:** This directory will check the environment, configuration, feature
> shapes, and supported options before training begins.
>
> **Why:** Early checks give beginners useful fixes quickly instead of letting a
> slow quantum run fail with a difficult internal error.

Future home of environment, configuration, shape, compatibility, and workload
checks. It should produce actionable diagnostics and an immutable compiled plan
before an expensive training run begins.
