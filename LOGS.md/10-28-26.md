# 10-28-26

## What did you push?

Completed the nested `qml-torch` v0.1 tool end to end. The package now has a
working installation configuration, typed experiment settings, PennyLane backend
adapter, angle encoding, Pauli-Z measurements, a trainable PyTorch quantum layer,
data validation, classical/VQC training, guided CLI, circuit/report output, a
beginner example, and 19 automated tests.

The runnable path is:

```text
cd qml-torch
pip install -e ".[dev]"
qml-torch run examples/train.py
```

## What did this accomplish?

The five first-version tasks are now implemented. A user can provide a trusted
`train.py` with `get_data()`, choose qubits, model mode, encoding, shots, and
measurement, then receive a classical/hybrid comparison and saved `results.json`.
The v0.1 scope stays intentionally small: 2–6 qubits, angle encoding, Pauli-Z
expectations, equal feature/qubit counts, and binary classification.

## Any errors?

The classical and hybrid metrics are experimental comparisons and do not
demonstrate quantum advantage. The tool executes the user's training script as
trusted code. PennyLane's current device-level shot deprecation is avoided by
setting shots on the QNode.

The local verification completed with 19 passing tests and Ruff reporting no
errors. Root CI now also installs and checks the nested package.
The root pytest configuration was narrowed to the root `tests/` directory so the
two packages keep separate test environments.

## Alpha 2 polish — 0.1.0a2

Summer requested a more complete, polished experience after testing alpha 1 on
TestPyPI. In this Codex-assisted pass, the team implementation was extended with:

- A built-in `demo` that works directly after package installation.
- `doctor` for environment/circuit checks and `init` for starter data scripts.
- Terminal progress and aligned comparison tables.
- Self-contained HTML dashboards with training curves, confusion matrices, and
  configuration/environment details, beside the JSON reports.
- F1, precision, recall, test loss, parameter counts, and per-epoch loss history.
- Saved configuration replay, data fingerprints, and explicit simulator seeding.
- Finite-shot input gradients, stricter tensor/config checks, and restoration of
  the caller's random streams.
- Failed/cancelled run artifacts and atomic writes per file.
- A separate CI matrix for Python 3.11–3.14, including distribution validation.

The new version is `0.1.0a2` because `0.1.0a1` was already uploaded to TestPyPI.
PennyLane 0.45.x requires Python 3.11+, now reflected in package metadata.
The existing contributors' work remains credited above; these additions were
implemented with Codex at Summer's request, not attributed to other team members.

Local verification of this pass includes 47 passing nested tests and a real
analytic demo and quantum environment check on Python 3.14.6. The CI matrix is
configured for additional Python versions; those remote runs are not yet verified.
Both alpha-2 distributions pass `twine check --strict`. The built wheel was
installed into a temporary virtual environment (using existing runtime
dependencies) and its `doctor` and finite-shot `demo` commands succeeded from
outside the source checkout. A local preview is saved in
`qml-torch/reports/demo.html`; generated reports are excluded from Git.
