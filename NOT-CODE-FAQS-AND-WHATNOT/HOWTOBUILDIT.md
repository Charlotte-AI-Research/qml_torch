# How the team will build it

We will keep the first release small: a two-qubit simulator layer, a tutorial, tests, and a reproducible baseline. Students can contribute through code, experiments, documentation, testing, or outreach.

Every experiment records its dataset, seed, model, metric, and runtime. Every code change has a focused review and a check that another student can run. Larger research questions need a separate proposal and do not become automatic team commitments.
